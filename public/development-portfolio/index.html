The working loop

Agents need useful tools, a reliable return path, and a clear way to ask for the human. These are separate jobs.

Agent Affordances

The tool surface

Small command-line tools make recurring engineering tasks concrete: read work items, delegate a bounded reasoning task, and inspect structural duplication.

The audited snapshot includes linear-reads, afford-spark and afford-dry. Their interfaces are the useful unit to inspect.

Hive

The coordination service

Hive connects development sessions across machines and providers. A broker carries work and responses; local edges connect those deliveries to the sessions that can act on them.

Attention is a human-intervention queue on that foundation. An agent can ask for a decision while the human keeps working.

The Weave

The engineering organisation

The Weave is the team and its working agreements: named responsibilities, task dispatch, independent review, delivery and lessons carried into later work.

Hive handles coordination. The Weave supplies the engineering practice around it.

Snapshot and counting method

This map draws on the repository inventory captured on 13 October 2026, with activity counted from 13 April 2025. The linked product surfaces and notification note reflect subsequent work identified above.

47 non-fork repositories
The core inventory. It included 42 repositories containing counted source code; forks were recorded separately.
104 package locations · 95 identities
Named package or application manifests, with identities deduplicated by ecosystem and declared name.

Source counts in the original inventory excluded dependencies, identified generated output and mirrored plugin trees. A second total removed byte-identical source files across repositories. Test counts described declarations, not passing executions; commits and merged changes described activity within the stated window.

Repository descriptions came from source trees, manifests, readme files and implementation-bearing branches. These definitions keep the snapshot comparable without making code volume the measure of a product.
